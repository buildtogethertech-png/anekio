How to use these runbooks

  1. Read the Preconditions. Confirm the server, database, PostgreSQL version, free disk, and access level.
  2. Set the variables. Replace every uppercase placeholder before copying later commands.
  3. Run one block at a time. Read its output; never paste the entire page into a terminal.
  4. Stop on unexpected output. Preserve logs and ask for review instead of improvising destructive commands.
  5. Complete verification. A command finishing is not the same as a successful recovery.
