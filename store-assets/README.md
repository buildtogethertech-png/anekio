# Google Play listing assets

Upload these files in Google Play Console → Store settings:

| Play Console field | File | Verified requirement |
| --- | --- | --- |
| App icon | `anekio-play-icon-512.png` | PNG, 512 × 512 px, 168 KB |
| Featured graphic | `anekio-play-featured-graphic-1024x500.png` | PNG, 1024 × 500 px, 669 KB |

The icon is derived from Anekio's existing application icon. The featured
graphic is a text-free branded illustration, so no store-listing text becomes
unreadable at small sizes.
